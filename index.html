SYNOPSIS

ravindu [--hunt exposure] [--red-team org] [--pentest scope] [--review repo ...] [--disclose cna] [--mentor team]

DESCRIPTION

ravindu breaks things so they can be fixed before somebody else breaks them for real.

Currently leads threat operations: finding exposed services across the internet before attackers do, attributing them to the right owner, and turning raw findings into advisories that customers and brokers can actually act on.

Before that, a stretch in offensive security — red team engagements mapped to MITRE ATT&CK, Active Directory attack paths, web and API testing for Nordic enterprises and a global bank, and leading a team of junior testers. Earlier still, the defensive side: running EDR/XDR, firewalls and identity controls, and writing the policies behind them.

Off hours: auditing open-source software. Parsers, network daemons, WordPress plugins — anything that takes untrusted input and trusts it a little too much. Findings go to the maintainer first, then to a CNA, then here. See ADVISORIES.

In IT since 2019, in security since 2022. Prefers plain text, short reports, and proofs of concept that reproduce on the first try.
